# openRTLinux v0.4.0

Everything from v0.3.0, plus the things a week of real typing asked for: your own words,
a fix hotkey that fixes without judging, a pause chord, code mode, and an About section
that can tell you what version you are running.

## My words

A place for your own vocabulary, because some of what gets "fixed" is not a typo at all.
Both lists live in `~/.config/openrtlinux/words.toml` and are edited in the settings
window:

* **Words that are never fixed.** They arrive three ways: typed in by hand, learned after
  the same English word shows up three times, or kept the moment you reverse one of our
  fixes - Undo, or pressing the fix hotkey on a word we already fixed, is an explicit
  "that spelling was right".
* **Pairs** - `what I typed = what it should be`. Checked before every other rule and
  applied both when you type a space and when you press the fix hotkey: an exact string
  you typed is not a guess.

Automatic learning is a switch; the words you add by hand (and the ones you keep) are
never forgotten.

## A press that always converts

The fix hotkey used to refuse when the word on screen looked like a real word, so that an
accidental press could not mangle it. A press is not an accident: it now converts whatever
is under the cursor - the word checker first, then the other layout's reading, real word
or not. "A real word stays put" is still the rule for the automatic path, where nobody
asked for a fix.

## Ctrl+Alt+P pauses the fixing

One chord stops the fixing and the same chord brings it back, without opening the tray;
the tray icon turns grey while it is paused. It is the one place a shortcut is read, so it
does not collide with typing.

## Code mode

Off by default, on with a checkbox: nothing shaped like a name is touched (`camelCase`,
`snake_case`, `CONSTANT`, digits, `_ . :: ->`), and Thai that reads as a name goes back to
English even though no dictionary knows it - `suvasin` typed on the Thai keyboard is a
name, not a misspelling. With it on, the fix hotkey leaves those tokens alone too.

## About, and a version you can check

The bottom of the settings window says which version the running daemon reports, links to
this repository, and has **Check for updates**: one request to the GitHub API when you
press it, versions compared as numbers, and the answer as text. Nothing is downloaded and
nothing goes online on its own.

## Also fixed

* A word kept as typed is shape-checked first: the first real swap stored `vvdde]y'`, which
  was a stuck key.
* `auto` mode keeps the swap from its last fix, so the Undo button works in every mode.
* 355 unit tests pass (`cargo test --lib --features linuxos`).

## Where it runs

```bash
cd ~/Cursor/righttype-publish
bash packaging/linux/install.sh --release --with-tray
```

Ubuntu (tested on 26.04 + GNOME/Wayland) and read/write access to `/dev/uinput`.
